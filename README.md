# GitHub-Security-Scan-Tool

## Version Information
- Version: 4.0.0
- Version: 2.0.0
- Created: February 2025
- Last Updated: June 2025

## Technical Details
- Node.js Version: 22.14.0
- Trivy Version: 0.55.0

## Features
- Static code analysis with CodeQL
- Dependency vulnerability scanning with npm audit
- File system scanning with Trivy
- Automated email reporting
- Support for both frontend and backend code scanning
- Configurable scan targets and parameters

## Prerequisites
- GitHub repository access
- Appropriate permissions to run workflows
- Valid email address for receiving reports

## Quick Start
1. Navigate to Actions in the Matcha repository
2. Select "Security Scan" workflow
3. Click "Run workflow"
4. Fill in required parameters:
   - Repository name
   - Frontend/backend directory names
   - Branch to scan
   - Recipient email
